
# Pipeline de Predicción de Precios

Para ejecutar esta pipeline, sigue estos pasos:

1. Copia la ruta del archivo que contiene las propiedades, sin incluir comillas dobles ni simples, solo el nombre del archivo.
2. Abre una terminal y dirígete a la carpeta que obtuviste al descomprimir el archivo zip en el que se encuentra esta pipeline.
3. Ejecuta el siguiente comando para iniciar la ejecución: `python main.py`
4. Haz clic en "Predecir" e ingresa en la consola la ruta del archivo que copiaste en el paso 1.
5. En la misma carpeta, se generará un archivo CSV llamado "predicciones", donde encontrarás las variables utilizadas por el modelo y el precio predicho.
6. En la consola, se mostrarán algunas métricas importantes del modelo en relación con los datos de tus propiedades.
